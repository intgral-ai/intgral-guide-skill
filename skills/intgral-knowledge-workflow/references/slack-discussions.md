# 当日 Slack 讨论同步到 Founders docs

仅在明确授权的受众和来源范围运行。来源频道与命令/回帖频道分别登记；允许读取一个 Team 频道，不代表允许在那里执行命令或发布 Founders 内容。

可将已获授权的内部来源频道另行登记为召唤入口，仅接受已核验 founders 的真实 @mention。入口与结果目的地分开：较广受众的原线程只发送固定、中性的收件提示；请求沿原始来源身份进入登记的私密线程，分析、文档链接、待确认、结果及错误详情都留在私密线程。先核验私密目的地，再读取私有资料；来源变更、外部共享或 bot 已退出则阻断。新频道和 DM 不因同名 bot 自动取得接入权。

## 读取边界

以私有配置时区的当天零点和本次请求时间固定窗口。先完整分页枚举 API 留存的主消息，再读取可能含当日回复的旧线程，不能只用 `oldest=今天`。保留旧父帖与早期回复作为上下文，并区分窗口内新增内容。登记实际频道、分页/线程覆盖、截止时间、保留策略与不可读项；新频道先取得访问并登记，不宣称覆盖隐藏私密频道或已删除历史。

Slack `is_limited` 表示历史受保留策略限制。可以同步实际已读的留存证据，但必须保留该提示，不把不可见历史说成已读。接口失败、分页中断、图片未读和权限不足是执行缺口，保存 pending，不能记成没有新内容。

## 图片和并行阅读

用实际有权限的身份读取 Slack 文件。PNG/JPEG/WebP 的完整像素经过大小、类型和来源检查后，实际附加给多模态阅读器；文件名、链接、OCR猜测或连接器返回的文件引用不等于看过图片。公开预览图仅从登记的 HTTPS 主机读取，不携带 Slack 凭证，不跟随不明重定向。未知来源和不支持格式保留缺口。

可按频道并行安排只读阅读器。每个阅读器仅收到它需要的消息、图片和来源标识，不收到凭证、写工具或外发权限。先给每项发现关联原始消息，再由统一编辑器对照负责人原话、反证和当前文档分类。图片中的 AI 草稿和他人的转述不能作为负责人确认。

## 正式记录与 Decision

正式 Founders 文档须核对集合默认权限、直接成员、群组成员、父文档继承和公开分享；接口读不全或受众漂移就暂停该目标。共享 Product 文档不能作为 Founders 私有暂存；需要私有正式版本时，先建立同权限文档并登记映射，不改共享稿的权限或内容。

已定结论要求有权负责人的原始明确确认与准确适用范围。建议、候选、疑问、否定确认、PR 合并和 bot 自报不能据此升级产品承诺。探索保留为探索，未决问题进入既有稳定 Decision 主题线程；独立更新可以继续，不因某项待确认而丢弃全部结果。

每个目标由一个宿主写入者处理：重读来源与文档 → 核对 revision → 最小补丁 → 完整读回 → 保存收据。保留人工基线；源消息变更、并发编辑或权限变化则暂停。多文档部分成功时，在原线程明确已验证目标和未完成目标；不自动重写或回滚已成功部分。

同受众原线程或已核验的私密结果线程回帖包含实际改动、每份已修改文档的标题和可点击链接、待确认线程和覆盖限制。登记 Decision 主入口时，结果集中到对应 Decision 线程；较广受众入口仅收固定收件提示。Team 关闭时不自动向 Team docs、日报、任务或频道输出 Founders 内容；另行明确批准的公开 Linear 任务只发布核对过的具体稿件，见 [slack-interface.md](slack-interface.md)。重跑通过事件、来源记录和逐目标收据去重，复用私密结果线程，未知写入结果先核对远端。

## 触发

每次召唤核对 Decision。普通线程回复是否唤醒执行器，以已部署事件/轮询入口为准；未实现的日轮询不能写成自动闭环。Wispr 同步另做连接器、账号及真实读取检查，纯 Slack 请求不声称已同步 Wispr。
