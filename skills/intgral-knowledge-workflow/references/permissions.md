# 权限继承与发布门槛

成熟阶段不决定受众。先确定 personal / founders / team，再选择目标 docs、Decision、通知与执行身份；所有衍生记录、日志和报错继承来源中最严格的可见范围。

- personal：仅 owner；My thoughts 与独立笔记默认这里，明确选定内容和受众后才可转出。
- founders：仅当前已确认白名单；来源、提案、决定、产品草稿和所有直接衍生物保持私有。
- team：明确可共享的来源及独立批准的执行版本；不能读取 founders 原文来做团队摘要。
- unknown/conflict：owner-only 待处理，先解决分类问题。

docs 的集合默认权限、用户/组、单文档/子树分享及公开链接都需要核对。频道私密不证明 docs 私密；页名/标签不能建立权限边界。团队执行身份不得获得私密源账号、文档、状态队列、历史聊天或检索索引的读取权。不能隔离时保持 Team 自动发布关闭。

发送前重新验证目的地仍私密且成员符合白名单。新增成员不自动扩展其他系统权限；发现漂移阻断受影响发布，在原私有范围报告。角色或频道成员身份不自动授予所有决定或对外发布的批准权。

Founders → Team 只发送单独获批的精确版本。不得移动原私有页面来公开全文、附件与历史；不得在 Team 消息中附私有源链接。内容、重要来源或目标改变后旧发布批准不再适用。未经明确发布批准，确认采用仍留私有。
